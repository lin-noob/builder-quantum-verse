# 多语言配置页面使用说明

## 功能概述

多语言配置页面是一个用于管理网站多语言文案的管理界面，采用主从布局结构：

- **左侧菜单分类列表**：显示所有文案分类
- **右侧翻译文案列表**：显示选中分类下的所有翻译文案
- **支持增删改查操作**：可以对翻译文案进行完整的 CRUD 操作
- **导入导出功能**：支持批量导入和导出翻译文件

## 页面结构

### 主从布局
- **左侧区域**：菜单分类列表
  - 显示所有文案分类（如导航菜单、首页横幅等）
  - 点击分类可筛选右侧文案列表
  - 显示每个分类下的文案数量

- **右侧区域**：翻译文案列表
  - 显示选中分类下的所有翻译文案
  - 每行显示 Key、中文、英文三个字段
  - 支持搜索过滤功能
  - 提供新增、编辑、删除操作按钮

### 功能按钮
- **导入**：从 JSON 文件导入翻译文案
- **导出**：将当前所有翻译文案导出为 JSON 文件
- **新增文案**：添加新的翻译文案
- **编辑**：修改现有翻译文案
- **删除**：删除翻译文案

## 使用方法

### 浏览翻译文案
1. 在左侧分类列表中点击任一分类
2. 右侧将显示该分类下的所有翻译文案
3. 可使用顶部搜索框按 Key 或翻译内容进行过滤

### 新增翻译文案
1. 点击右上角"新增文案"按钮
2. 在弹出对话框中填写 Key、中文、英文内容
3. 点击"添加"按钮保存

### 编辑翻译文案
1. 在文案列表中点击某行的"编辑"按钮
2. 在弹出对话框中修改中文或英文内容
3. 点击"保存"按钮保存修改

### 删除翻译文案
1. 在文案列表中点击某行的"删除"按钮
2. 确认删除操作

### 导入翻译文件
1. 点击右上角"导入"按钮
2. 选择包含翻译文案的 JSON 文件
3. 系统将自动导入文件中的所有翻译文案

### 导出翻译文件
1. 点击右上角"导出"按钮
2. 系统将自动下载包含所有翻译文案的 JSON 文件

## API 接口

### 菜单分类相关
- `GET /api/admin/api/v1/i18n/categories` - 获取所有菜单分类

### 翻译文案相关
- `GET /api/admin/api/v1/i18n/translations` - 获取所有翻译文案
- `POST /api/admin/api/v1/i18n/translations` - 创建新的翻译文案
- `PUT /api/admin/api/v1/i18n/translations` - 更新翻译文案
- `DELETE /api/admin/api/v1/i18n/translations/{id}` - 删除翻译文案
- `GET /api/admin/api/v1/i18n/translations/export` - 导出翻译文案
- `POST /api/admin/api/v1/i18n/translations/import` - 导入翻译文案

## 数据结构

### 菜单分类 (MenuCategory)
```typescript
interface MenuCategory {
  id: string;     // 分类ID
  name: string;   // 分类名称
  count: number;  // 包含的文案数量
}
```

### 翻译文案 (TranslationItem)
```typescript
interface TranslationItem {
  id: string;   // 唯一标识符
  key: string;  // 翻译键名，采用 "分类.键名" 格式
  zh: string;   // 中文翻译
  en: string;   // 英文翻译
}
```

## 注意事项

1. **Key 命名规范**：建议采用 "分类.具体功能.文案名称" 的格式，如 "nav.home.title"
2. **数据备份**：在执行导入操作前，建议先导出当前数据作为备份
3. **权限控制**：该页面应仅对具有相应权限的管理员开放
4. **性能考虑**：对于大量翻译文案的情况，建议实现分页加载
