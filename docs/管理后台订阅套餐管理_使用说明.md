# 管理后台订阅套餐管理功能使用说明

## 功能概述

订阅套餐管理功能允许超级管理员创建、编辑、删除和配置平台的订阅套餐。每个套餐可以包含不同的功能权限，组织可以根据需要选择合适的套餐。

## 页面结构

该功能采用主从结构设计：

- **左侧区域**：套餐列表，支持增删改查操作
- **右侧区域**：功能配置面板，用于配置套餐包含的功能权限

## 功能说明

### 1. 套餐管理

#### 创建新套餐
1. 点击左侧套餐列表上方的"新建"按钮
2. 在弹出的对话框中填写套餐信息：
   - 套餐名称
   - 套餐描述
   - 套餐价格
   - 套餐时长（月付/年付/永久）
3. 点击"保存"按钮完成创建

#### 编辑套餐
1. 在套餐列表中找到需要编辑的套餐
2. 点击套餐右侧的"更多"按钮（三个点图标）
3. 选择"编辑"选项
4. 修改套餐信息后点击"保存"

#### 复制套餐
1. 在套餐列表中找到需要复制的套餐
2. 点击套餐右侧的"更多"按钮
3. 选择"复制"选项
4. 系统将创建一个同名但ID不同的新套餐

#### 删除套餐
1. 在套餐列表中找到需要删除的套餐
2. 点击套餐右侧的"更多"按钮
3. 选择"删除"选项
4. 在确认对话框中点击"确定"完成删除

### 2. 功能配置

#### 选择套餐
1. 在左侧套餐列表中点击任一套餐
2. 右侧功能配置面板将显示该套餐的配置信息

#### 配置功能权限
1. 在右侧功能配置面板的左侧选择功能模块
2. 在右侧功能列表中勾选需要包含在套餐中的功能
3. 点击页面底部的"保存修改"按钮保存配置

#### 功能模块说明
- **AI营销**：包含AI策略相关的功能
- **数据分析**：包含数据分析和报告相关的功能
- **用户管理**：包含用户管理相关的功能
- **系统管理**：包含系统设置、权限管理等高级功能

## 使用场景

1. **创建新套餐**：为不同规模的客户提供不同的功能组合
2. **调整套餐功能**：根据市场需求调整套餐包含的功能
3. **套餐定价**：通过配置不同功能组合来制定差异化定价策略

## 注意事项

1. 删除套餐前请确认没有组织正在使用该套餐
2. 修改套餐功能可能会影响已订阅组织的使用权限
3. 建议在修改套餐配置前先备份当前配置

## 访问路径

管理后台 → 订阅套餐

或直接访问：`/admin/subscriptions`
