# SaaS平台精细化权限管理系统使用说明

## 概述

SaaS平台精细化权限管理系统是为组织内部用户设计的基于角色 (RBAC) 的权限管理解决方案，支持功能级和字段级的双重权限控制。该系统为组织管理员提供了直观的图形化界面，用于管理组织内的所有角色与权限，确保不同岗位的用户只能访问其职责范围内的功能与数据。

## 功能模块

### 1. 角色管理

#### 1.1 角色列表
- 显示组织内所有角色及其基本信息
- 支持通过角色名称或描述进行搜索筛选
- 每个角色显示其拥有的功能权限数量

#### 1.2 角色操作
- **新建角色**：创建全新的角色定义
- **编辑角色**：修改现有角色的名称和描述
- **复制角色**：基于现有角色创建新角色，提高配置效率
- **删除角色**：移除不再需要的角色（有二次确认）

### 2. 功能权限配置

#### 2.1 权限分组
权限按业务模块进行分组，包括：
- 用户管理
- AI营销
- 数据分析
- 其他业务模块

#### 2.2 权限配置
- 通过复选框为角色分配功能权限
- 支持按模块展开/收起权限配置
- 每个权限项包含详细描述信息

### 3. 字段权限配置

#### 3.1 字段权限管理
- 通过"配置字段权限"按钮打开字段权限配置模态框
- 以表格形式展示资源的所有字段
- 支持为每个字段单独设置查看和编辑权限

#### 3.2 权限逻辑
- 勾选"编辑"权限时，自动勾选"查看"权限
- 取消"查看"权限时，自动取消"编辑"权限
- 表头提供列级别的全选/全不选功能

### 4. 用户权限分配

#### 4.1 用户列表
- 显示组织内所有成员及其基本信息
- 展示每个用户当前分配的角色

#### 4.2 角色分配
- 通过下拉选择器为用户分配一个或多个角色
- 支持随时调整用户的角色分配

## 使用流程

### 1. 创建新角色
1. 点击"新建角色"按钮
2. 输入角色名称和描述
3. 点击"保存"创建角色

### 2. 配置角色权限
1. 在角色列表中点击要配置的角色
2. 在右侧权限配置面板中：
   - 选择需要的业务模块
   - 展开模块查看功能权限
   - 勾选需要的功能权限
   - 点击"配置字段权限"按钮设置字段级权限
3. 点击"保存修改"保存权限配置

### 3. 为用户分配角色
1. 在用户权限分配表格中找到目标用户
2. 点击对应行的下拉选择器
3. 选择要分配的角色
4. 角色会立即生效

## 最佳实践

### 1. 角色设计原则
- 遵循最小权限原则，只分配工作所需的最小权限集合
- 根据岗位职责设计角色，避免过于宽泛的角色定义
- 对于职责相似的岗位，使用复制功能创建新角色并微调

### 2. 权限配置建议
- 定期审查角色权限，确保符合当前业务需求
- 对于敏感数据字段，严格控制查看和编辑权限
- 重要权限变更应有操作记录和审核流程

### 3. 用户管理规范
- 新员工入职时，及时为其分配合适的角色
- 员工岗位变动时，及时调整其角色分配
- 离职员工应及时禁用账户或移除所有角色

## 常见问题

### 1. 权限不生效怎么办？
- 确认权限配置已保存
- 确认用户已分配了正确的角色
- 检查是否有冲突的权限设置

### 2. 如何批量为多个用户分配相同角色？
- 系统支持为用户逐个分配角色
- 对于批量操作需求，建议通过用户管理页面逐一设置

### 3. 删除角色时需要注意什么？
- 删除角色前系统会显示二次确认弹窗
- 删除角色会同时移除所有用户的该角色分配
- 系统角色无法删除，只能修改权限

## 技术说明

### 1. 权限同步机制
- 权限配置与项目代码保持同步
- 系统自动扫描项目代码生成权限清单
- 提供权限差异检测和修复工具

### 2. 安全保障
- 严格遵循"默认拒绝"原则
- 所有权限校验在后端强制执行
- 前端仅做界面展示，不参与权限判断
