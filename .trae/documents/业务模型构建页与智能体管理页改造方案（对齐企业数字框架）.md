## 总体设计变更
- 目标：将现有“单模型完备”改造为“企业层共享 + 模型层引用”的双层架构。
- 企业层（已新增原型页）承载四类全局注册表：Entities、Capabilities、Rules、Events；统一、只读、可复用。
- 业务模型层仅做引用与轻量扩展（local_extensions），流程改为事件驱动的能力编排。
- 智能体层定位为“策略执行体”，在模型语境下订阅企业事件、调用企业能力、遵守企业规则。

## 数据模型重构
- 全局注册表（只读）：
  - Entity：{id,name,type,description,referencedBy}
  - Capability：{id,name,description,inputEntityId,outputEntityId,risk,callableByAgent}
  - Rule：{id,name,ruleType,severity,scope,referencedCount,description}
  - Event：{id,name,triggerEntityId,condition,subscribableByAgent,description}
- 业务模型（Domain Slice）：
  - { model_id, entities:[{ref, usage, local_extensions}], actions:[{ref, context}], rules:[{ref}], processes:[{name, steps:[{event}|{action}]}] }
- 智能体（策略执行体）：
  - { agent_id, subscribed_events:[{ref, filter?}], allowed_capabilities:[{ref, context?}], rule_compliance:[{ref}], context_bindings:[model_id], constraints, telemetry }

## 前端页面改造：智能体管理页
- 文件位置： [AgentManagement.tsx](file:///c:/Users/Administrator/Desktop/CDP/client/pages/AgentManagement.tsx)
- 改造点：

    - 概览：基本信息、当前订阅事件、能力白名单、规则遵循状态。

  - 操作边界：不允许在此页创建/修改企业层对象；仅在设计模式下调整订阅/白名单/上下文绑定（均为 UI Mock）。

```json
{
  "model_id": "Customer_Complaint",
  "entities": [
    { "ref": "Customer", "usage": "read", "local_extensions": {"complaint_count": "number"} },
    { "ref": "Ticket", "usage": "read/write" }
  ],
  "actions": [ { "ref": "SendApology", "context": "Complaint" } ],
  "rules": [ { "ref": "RefundLimitRule" } ],
  "processes": [
    { "name": "HandleComplaint", "steps": [
      { "event": "Ticket.Created" },
      { "action": "AnalyzeSentiment" },
      { "action": "SendApology" }

  ]

```

```json
{
  "agent_id": "SupportBot",
  "subscribed_events": [ { "ref": "Ticket.Created" } ],

  "rule_compliance": [ { "ref": "AgentAccessControl" } ],
  "context_bindings": [ "Customer_Complaint" ],
  "constraints": { "rate_limit_per_min": 60 },
  "telemetry": { "last_24h_calls": 128 }

```
