# 导入导出中心功能设计文档

## 1. 概述

### 1.1 功能背景
导入导出中心功能旨在为用户提供统一的数据导入和导出管理界面，支持用户将外部数据导入到系统中以及将系统数据导出到外部文件。该功能将采用应用已有的标准列表样式，确保与现有UI设计保持一致。

### 1.2 功能目标
- 提供统一的导入任务管理界面
- 提供统一的导出任务管理界面
- 支持导入导出任务的状态跟踪
- 提供任务历史记录查询功能
- 支持标准列表样式展示任务信息

## 2. 功能架构

### 2.1 整体架构
导入导出中心将分为两个主要模块：
1. 导入中心：管理所有数据导入任务
2. 导出中心：管理所有数据导出任务

### 2.2 技术架构
- 前端：React + TypeScript + Tailwind CSS
- 组件：使用现有的UI组件库（Card, Table, Button等）
- 路由：基于React Router v6

## 3. 功能模块设计

### 3.1 导入中心模块

#### 3.1.1 功能描述
导入中心用于管理所有数据导入任务，包括用户上传文件、任务状态跟踪、导入结果查看等功能。

#### 3.1.2 页面结构
```
导入中心
├── 搜索和筛选区域
│   ├── 搜索框（按任务名称、文件名搜索）
│   ├── 状态筛选器（全部、进行中、成功、失败）
│   ├── 时间筛选器（开始时间、结束时间）
│   └── 操作按钮（刷新、创建导入任务）
├── 导入任务列表
│   ├── 任务ID
│   ├── 任务名称
│   ├── 文件名
│   ├── 文件大小
│   ├── 状态
│   ├── 创建时间
│   ├── 完成时间
│   └── 操作（查看详情、重新导入、删除）
└── 分页控件
```

#### 3.1.3 数据模型
```typescript
interface ImportTask {
  id: string;              // 任务ID
  name: string;            // 任务名称
  fileName: string;        // 文件名
  fileSize: number;        // 文件大小（字节）
  status: 'pending' | 'processing' | 'success' | 'failed'; // 状态
  createdBy: string;       // 创建人
  createdAt: string;       // 创建时间
  finishedAt?: string;     // 完成时间
  progress: number;        // 进度（0-100）
  recordsProcessed: number; // 已处理记录数
  recordsFailed: number;    // 失败记录数
  errorMessage?: string;   // 错误信息
}
```

### 3.2 导出中心模块

#### 3.2.1 功能描述
导出中心用于管理所有数据导出任务，包括创建导出任务、任务状态跟踪、下载导出文件等功能。

#### 3.2.2 页面结构
```
导出中心
├── 搜索和筛选区域
│   ├── 搜索框（按任务名称、导出内容搜索）
│   ├── 状态筛选器（全部、进行中、成功、失败）
│   ├── 时间筛选器（开始时间、结束时间）
│   └── 操作按钮（刷新、创建导出任务）
├── 导出任务列表
│   ├── 任务ID
│   ├── 任务名称
│   ├── 导出内容
│   ├── 文件大小
│   ├── 状态
│   ├── 创建时间
│   ├── 完成时间
│   └── 操作（下载、查看详情、重新导出、删除）
└── 分页控件
```

#### 3.2.3 数据模型
```typescript
interface ExportTask {
  id: string;              // 任务ID
  name: string;            // 任务名称
  contentType: string;     // 导出内容类型（用户数据、行为数据等）
  fileSize?: number;       // 文件大小（字节）
  status: 'pending' | 'processing' | 'success' | 'failed'; // 状态
  createdBy: string;       // 创建人
  createdAt: string;       // 创建时间
  finishedAt?: string;     // 完成时间
  progress: number;        // 进度（0-100）
  downloadUrl?: string;    // 下载链接
  errorMessage?: string;   // 错误信息
}
```

## 4. UI设计规范

### 4.1 页面布局
采用标准列表页面布局，包含：
- 顶部标题区域
- 搜索和筛选区域（Card组件）
- 任务列表区域（Card组件）
- 分页控件区域

### 4.2 组件规范
- 使用现有的Card组件作为容器
- 使用标准Table组件展示任务列表
- 使用Button组件作为操作按钮
- 使用Select组件作为筛选器
- 使用Input组件作为搜索框

### 4.3 状态显示规范
- 进行中：蓝色标签
- 成功：绿色标签
- 失败：红色标签
- 等待中：灰色标签

### 4.4 样式规范
- 遵循项目设计系统规范
- 使用紫色主题色作为主色调
- 保持与现有页面一致的间距和排版

## 5. 路由设计

### 5.1 路由路径
```
导入中心：/import-center
导出中心：/export-center
```

在主菜单中添加"导入导出中心"菜单项，包含两个子菜单：
- 导入中心
- 导出中心
