# 系统管理 - 订阅套餐与充值记录功能设计文档

## 1. 概述

### 1.1 功能背景
为AI营销平台的SaaS用户提供订阅套餐管理和充值记录查看功能，使用户能够：
- 查看当前订阅套餐信息
- 浏览历史充值记录
- 了解套餐功能权限
- 进行套餐续费和升级操作

### 1.2 功能目标
- 提供清晰的订阅套餐展示界面
- 实现充值记录的列表化展示
- 支持套餐升级/续费操作引导
- 保持与现有系统管理菜单结构的一致性
- 遵循平台UI设计规范

### 1.3 设计原则
1. **一致性原则**：遵循平台现有的设计语言和交互模式
2. **简洁性原则**：界面简洁明了，信息层次清晰
3. **易用性原则**：操作流程简单直观
4. **安全性原则**：确保数据安全和权限控制

## 2. 页面结构设计

### 2.1 整体布局
采用上下结构设计：
- 顶部：当前订阅套餐信息展示区域
- 中部：充值记录列表区域
- 底部：操作按钮区域

### 2.2 组件层级结构
```
SubscriptionRecharge (页面根组件)
├── SubscriptionCard (套餐信息展示)
│   ├── PackageFeatureList (功能列表)
│   └── PackageActionButtons (操作按钮)
└── RechargeHistoryTable (充值记录表格)
    ├── SearchFilter (搜索过滤器)
    ├── RechargeTable (记录表格)
    └── Pagination (分页组件)
```

## 3. 功能设计

### 3.1 订阅套餐管理

#### 3.1.1 套餐展示
- 显示当前订阅套餐信息（名称、价格、到期时间）
- 展示套餐包含的功能权限列表
- 提供套餐升级/续费操作入口
- 显示套餐使用统计信息

#### 3.1.2 套餐类型
1. **基础版**
   - 价格：¥99/月
   - 功能：AI策略查看、用户列表查看

2. **专业版**
   - 价格：¥299/月
   - 功能：AI策略创建编辑、用户管理、数据分析

3. **企业版**
   - 价格：¥999/月
   - 功能：全部功能

### 3.2 充值记录查看

#### 3.2.1 记录列表
- 显示历史充值记录（订单号、时间、金额、支付方式、状态）
- 支持按时间范围筛选
- 支持按支付状态筛选
- 支持分页功能
- 支持刷新数据

#### 3.2.2 记录详情
- 显示单笔充值的详细信息
- 包含订单号、支付时间、金额明细
- 显示支付凭证信息
- 提供下载/打印功能

## 5. UI数据模型

### 5.1 订阅套餐展示模型
```typescript
interface SubscriptionPackage {
  id: string;             // 套餐ID
  name: string;           // 套餐名称
  description: string;    // 套餐描述
  price: number;          // 价格
  duration: string;       // 套餐时长("月付" | "年付" | "永久")
  features: string[];     // 功能列表
  isActive: boolean;      // 是否激活
  expiryDate: string;     // 到期时间
}

interface CurrentSubscription {
  package: SubscriptionPackage;  // 当前套餐
  startDate: string;             // 开始时间
  expiryDate: string;            // 到期时间
  status: "active" | "expired" | "pending"; // 状态
}
```

### 5.2 充值记录展示模型
```typescript
interface RechargeRecord {
  orderId: string;        // 订单号
  orderTime: string;      // 订单时间
  amount: number;         // 金额
  paymentMethod: string;  // 支付方式
  status: string;         // 状态
  currency: string;       // 货币
  description?: string;   // 描述
}
```

## 8. 交互设计规范

### 8.1 页面访问权限
- 仅组织管理员角色可访问此页面
- 普通成员无法查看此功能

### 8.2 用户操作流程
1. 用户点击系统管理菜单
2. 展开子菜单，点击"订阅充值"
3. 进入订阅充值页面
4. 查看当前套餐信息
5. 浏览充值记录
6. 可选择续费或升级套餐
